About PageLens

PageLens Document Studio

Version 1.1.0 • Android Package: com.pagelens.ai

PageLens is an all-in-one mobile-responsive document workstation engineered for privacy, speed, and simplicity. Built with pure modern HTML, CSS, JavaScript, and packaged for Android using Capacitor.

Photos to PDF: High-resolution batch image conversion.
AI Document Scanner: Camera stream, Otsu filters, & Tesseract.js OCR.
AI Resume Maker: ATS-friendly dynamic builder with formatted A4 export.
Merge & Edit PDF: Lossless client-side merging & page management.
Compress PDF: Client-side JPEG rendering & PDF stream optimization.

Libraries: jsPDF, pdf-lib, pdf.js, tesseract.js, lucide, and @capacitor/core.

Privacy Policy & Security

100% Client-Side Privacy

All document operations (merging, scanning, converting, and rendering) occur within your local browser/device memory sandbox.

1. Local File Processing

When you select photos, PDFs, or use your camera, binary data is processed using browser Canvas and WebAssembly/JavaScript engines (jsPDF and pdf-lib). Your files are not uploaded to unauthorized servers.

2. Camera Permission

The Document Scanner requests camera permission only when you click "Start Camera". Video frames are processed locally on your device.

3. Local Storage Policy

We use localStorage strictly for non-sensitive UI settings such as theme preference and language choice.

4. AI & Backend Security

Frontend code contains no hardcoded private API keys. When connecting to an optional AI endpoint, requests are sent through your configured secure backend proxy.
